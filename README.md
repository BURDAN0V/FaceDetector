# FaceDetector

Это проект для обнаружения лиц на изображениях, видео и прямой трансляции с веб-камеры с использованием машинного обучения и OpenCV. Модели были обучены с использованием разнообразных наборов данных и теперь доступны для использования в различных приложениях.
